# ADS501-Consultancy-Project

ADS-501 Consultancy Project — LinkedIn Hiring Funnel & ATS Screening Analysis

## Project Overview

This project examines whether automated applicant tracking systems (ATS) and
recruiting screening tools are filtering out viable job candidates before a
human recruiter evaluates them. Using a dataset of scraped LinkedIn job
postings, this project explores where genuine talent scarcity ends and
recruiting-system friction begins, and what interventions might help
employers hire more responsibly as they restructure around AI-driven skill
needs.
